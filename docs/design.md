# 表单低代码设计器 设计文档

## 1. 产品最终形态

一个表单/文档低代码设计器，心智对标简化版 Word Online：

```
选纸张(A3/A4) → 选方向(横/纵) → 拖组件到内容区 → 实时看到离散分页 → 打印=预览
```

核心承诺：**所见即所得**（屏幕离散纸张 = 打印输出）。

设计器最终产出类似 Word 的文档，可用于打印；打印效果与页面显示效果一致。

## 2. 概念体系

### 2.1 纸张 Paper

物理规格，由两项配置决定：

| 配置   | 取值                   | 说明                        |
| ---- | -------------------- | ------------------------- |
| 纸张尺寸 | A3 / A4              | A3=420×297mm，A4=210×297mm |
| 纸张方向 | landscape / portrait | 横向 / 纵向                   |

尺寸与方向组合决定纸张的最终宽高（如 A3 landscape = 420mm 宽 × 297mm 高）。

### 2.2 页 Page

- 屏幕上一张离散纸 = 打印一页，**节=页（简化）**，统称 Page。
- 每页固定宽高（=纸张宽高），有边距。
- 每页结构（由外至内）：

```
┌─ Page (纸张宽×高) ─────────────────────┐
│  margin（左右边距；上下边距=0，由页眉/页脚占位） │
│  ┌─ 内容区 Content Area ────────────┐ │
│  │  ┌─ 页眉 Header ───────────────┐ │ │
│  │  │  每页顶部重复，贴纸张顶边      │ │ │
│  │  └──────────────────────────────┘ │
│  │  ┌─ 正文 Body ─────────────────┐ │ │
│  │  │  组件流（p / 图片 / 表格…）  │ │ │
│  │  └──────────────────────────────┘ │
│  │  ┌─ 页脚 Footer ───────────────┐ │ │
│  │  │  每页底部重复，贴纸张底边      │ │ │
│  │  └──────────────────────────────┘ │
│  └────────────────────────────────────┘
└────────────────────────────────────────┘

左右边距 + 内容区 = 纸张（上下边距=0）
页眉 + 正文 + 页脚 = 内容区高度
```

### 2.3 边距 Margin

- `@page margin: 0 <MARGIN>`（上下 0、左右可配，默认 12mm）。
- 上下边距由页眉/页脚占位（即使页眉/页脚未配置内容，仍占位 = 边距高度）。

### 2.4 内容区 Content Area

- 边距之内的可用区。
- 每页只有一个内容区（**移除"子表单容器"概念**）。
- 内容区里可放置各种组件和布局容器。
- 内容区可用高度：

```
内容区高 = 纸张高                 （上下边距=0）
正文可用高 = 纸张高 − 页眉高 − 页脚高
```

### 2.5 页眉 Header / 页脚 Footer / 页码 Page Number

概念与 Word 一致：

| 项             | 位置      | 行为                         | 备注                |
| ------------- | ------- | -------------------------- | ----------------- |
| 页眉 Header     | 内容区顶部   | 每页重复，贴纸张顶边                 | 可选；未配置时仍占位（高度=边距） |
| 页脚 Footer     | 内容区底部   | 每页重复，贴纸张底边                 | 可选；未配置时仍占位（高度=边距） |
| 页码 PageNumber | 放页眉或页脚内 | 每页显示当前页号（如"第 1 页 / 共 N 页"） | 由引擎自动计算注入         |

**页眉/页脚内容范围**：仅文本 + 页码占位符（不做组件容器）。格式固定 `第 {n} 页 / 共 {N} 页`。

> 已移除"标题"概念；页眉/页脚即承接原"标题每页重复"的语义。

### 2.6 组件 Component

可拖拽放入内容区的原子组件：

| 组件       | 说明                   |
| -------- | -------------------- |
| p（可编辑文本） | 段落标签，可直接编辑文字         |
| 图片       | 图片组件                 |
| 表格       | 长表格，**可跨页切分**（见 4.3） |

组件在正文 Body 中流式排列。

### 2.7 布局容器 Container

用于组织多个组件的复合容器：

| 容器      | 说明   |
| ------- | ---- |
| grid 容器 | 网格布局 |
| flex 容器 | 弹性布局 |

**关键约束：容器不跨页**——每个 grid/flex 容器整体位于一页内，超高则整体推到下一页（页面底部留白）。

> 跨页流动只支持"直接放在内容流里的组件"（p、图片、表格）；容器视为不可分割的块。

## 3. 设计过程

```
1. 选择纸张：A3 / A4
2. 选择纸张方向：landscape / portrait
3. 配置左右边距（默认 12mm）
4. （可选）配置页眉文本 / 页脚文本 / 显示页码
5. 选择组件，拖拽放置到内容区，即可查看渲染效果
6. 内容区高度超过纸张高度时，自动分页到下一页显示
```

## 4. 分页机制

### 4.1 核心约束：屏幕离散纸张需 JS 引擎

CSS `break-*` 属性**只在 print 媒介生效**，屏幕连续媒介不分页。因此：

- **屏幕端**（离散多张纸）：**必须 JS 分页引擎**——off-screen 渲染测高 → 按页可用高切分 → 渲染多个 Page → 每页注入页眉/页脚/页码。
- **打印端**：复用屏幕的 Page 结构（同一 DOM），`@page` 仅接管纸张尺寸与左右边距。

这是 Word Online / Google Docs 的共同做法，无法用纯 CSS 绕过。

### 4.2 页眉/页脚/页码的注入

- 引擎在生成每页 Page 时注入页眉/页脚文本。
- 页码：引擎知道当前页号 n 与总页数 N，按 `第 {n} 页 / 共 {N} 页` 注入到页眉或页脚的页码占位符位置。

### 4.3 表格跨页（特例）

表格是唯一允许"内容跨页"的组件：

```
表格被分页引擎按行切分：
  当前页能放多少行 → 放多少行
  剩余行 → 进入下一页（表头自动重复）
```

- 表头每页重复：每个表格切片都重新插入 thead。
- 单行不切断：`tr { break-inside:avoid }`。

### 4.4 容器不跨页

grid/flex 容器整体在一页内：

```
引擎处理：
  遇到容器 → 测其整体高度
  若当前页剩余高度 < 容器高度 → 容器整体推到下一页（当前页底部留白）
  容器内部不切分
```

### 4.5 超高组件处理

单个组件（如 grid、大图片）高度超过正文可用高时：

- **裁剪 + 警告**：只显示能放下的部分，引擎返回 `warnings: [{id, msg:'组件超高被裁剪'}]`，设计器在组件上叠加红色"超高"标记。
- 不允许超高组件跨页（v1 简化）。

## 5. 待定项 / 后续扩展

| 项       | v1 取值        | 后续可扩           |
| ------- | ------------ | -------------- |
| 纸张类型    | A3 / A4      | 自定义尺寸          |
| 边距      | 上下0/左右统一     | 四边独立配置         |
| 组件类型    | p、图片、表格      | 签名、勾选框、日期、分隔线  |
| 页眉/页脚内容 | 仅文本+页码       | 组件容器           |
| 容器跨页    | 不支持          | grid/flex 跨页切分 |
| 拖拽方案    | vuedraggable | —              |

## 6. 概念变更记录

相对此前讨论的调整：

| 概念      | 变更            | 理由                   |
| ------- | ------------- | -------------------- |
| 节 / 页   | 统一为 Page（节=页） | 简化，不引入 Word "节跨多页"语义 |
| 子表单容器   | **移除**        | 每页只有一个内容区，不再有区域块抽象   |
| 标题      | **移除**，语义并入页眉 | 统一为 Word 的页眉概念       |
| 页脚 / 页码 | **新增**        | 与 Word 对齐            |
| 容器跨页    | **不支持**       | v1 简化，跨页只支持流式组件      |
| 边距模型    | 上下0/左右统一      | 页眉页脚占位贴纸张顶/底边        |
| 页眉页脚内容  | 仅文本+页码        | 简化，不做组件容器            |
| 超高组件    | 裁剪+警告         | 不跨页                  |
