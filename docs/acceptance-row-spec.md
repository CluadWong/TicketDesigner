`design.md` §14、`design-biz.md` §13 均引用本表，不再内嵌行级细节，避免后续维护再次漂移。

- 字段名（`field`）取自参考实现 `demo/云铝-第二种作业票.html`，即回写 `data` 的键。

- `边框` 口径：外层 Grid 设 all 边框；单位/编号行内部可见单元格竖线，其余信息行合并后无行内竖线。

## 字段绑定约定

- 内嵌表为「单套行模板 + `minRows` 生成多行」，行模板中的字段名由渲染期按 **`列key_行号`** 自动派生（1-based 行号）：列 `工作地点` 第 r 行即 `工作地点_r`，两列 `工作地点`/`工作内容` 第 r 行即 `工作地点_r`/`工作内容_r`。故序号 5 的 8 个逐行键为 `工作地点_1..4` 与 `工作内容_1..4`（与 demoData 的 8 个键逐字对应）。
- 行模板内字段不写死（schema 留空），由列配置派生、逐行不冲突；表格内字段不可单独选中或配置，增删列即增删字段。

## 修订说明

- 本表取代 `design-biz.md` 旧版 §13 中「成员 = 五格行」「设备名称 = 两格行」的列数描述。
  参考实现里这两行实为 **colspan = 4 合并整行、行内无竖线**，并非 5 列或 2 列；以本表为准。
- 边框总规则：外层 Grid 设 all 边框；单位/编号行保留内部单元格竖线（带内部边框），其余信息行合并后无行内竖线。
- 2026-09-01：内嵌表字段改为渲染期按「列key_行号」自动派生（替换原 `{row}` 占位符方案）：行模板字段留空，由 `bindTableRowCell` 按列 key + 行号生成 `列key_行号`，逐行独立且与 data 键一致；表格内字段不可单独选中/配置。
- 字段名与 `demo/云铝-第二种作业票.html` 保持一致；若参考实现字段调整，本表须同步更新，并回填 P10 的参考图 / 参考 HTML。
- `工作任务` 在参考实现中是独立于基本信息块的表单块；在 V2 模型中作为外层 Grid 的第 5 个内部行，其右格内嵌一个 Table 节点，验收以**打印视觉一致**为准，不约束 DOM 分块方式。
