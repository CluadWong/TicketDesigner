# 开发计划

> 配套 [design.md](./design.md) 与 [engine.md](./engine.md)。本文档描述分阶段落地路径。

## 已锁定的技术决策

| 决策点 | 选型 |
|---|---|
| 页眉/页脚内容 | 仅文本 + 页码（不做组件容器） |
| 超高组件 | 裁剪 + 警告（不跨页） |
| 拖拽方案 | vuedraggable |
| 分页引擎 | off-screen 测高 + 按行/按块切分（已验证） |
| 屏幕与打印 | 复用同一 DOM 结构 |
| 边距模型 | 上下 0 / 左右统一 |
| 技术栈 | Vue 3 + TS + Vite + Element Plus |

## 阶段 1：项目骨架与 Schema（基础设施）

**目标**：搭好项目，定义数据契约，引擎函数化。

- [ ] 1.1 初始化 Vue 3 + TS + Vite + Element Plus 项目骨架
- [ ] 1.2 安装 vuedraggable
- [ ] 1.3 定义 Schema 类型体系（见 [engine.md §2](./engine.md#2-schema-类型定义)）
- [ ] 1.4 引擎抽函数化：`paginate(schema) → PaginateResult`，TS 类型
- [ ] 1.5 引擎单测：覆盖表格切分、容器不跨页、超高裁剪警告

**产出**：`FormSchema` 类型 + `paginate()` 纯函数 + 单测。

## 阶段 2：渲染器（只读视图）

**目标**：给 schema → 渲染出离散纸张，复刻 demo-v2 效果。

- [ ] 2.1 `<FormRenderer :schema :warnings>`：调 `paginate()` → `v-for <Paper>`
- [ ] 2.2 `<Paper>`：纸张容器 + 页眉槽 + 正文槽 + 页脚槽
- [ ] 2.3 组件渲染器：`<CompP>` `<CompImage>` `<CompTable>` `<CompGrid>` `<CompFlex>`
- [ ] 2.4 `usePrintStyle` composable：按 schema.paper 动态注入 `@page` 规则
- [ ] 2.5 打印集成：`window.print()` + 打印媒体查询
- [ ] 2.6 超高警告提示：在裁剪组件上叠加红色"超高"标记

**产出**：只读渲染器，能渲染 schema 为离散纸张 + 打印 + 警告。

## 阶段 3：设计器画布（可编辑）

**目标**：拖拽编辑 schema，实时预览。

- [ ] 3.1 左侧组件面板：p / 图片 / 表格 / grid / flex
- [ ] 3.2 中间画布：承载 `<FormRenderer>`，正文组件列表用 vuedraggable（拖拽排序、可选中）
- [ ] 3.3 右侧属性面板：编辑选中组件属性（文本、列数、宽高…）
- [ ] 3.4 顶部工具栏：纸张选择、方向切换、边距配置、页眉/页脚文本与页码开关、打印按钮
- [ ] 3.5 从面板拖到画布 → push 进 `schema.body`
- [ ] 3.6 编辑后 debounce 重算分页（300ms）

**产出**：可视化设计器，拖拽编辑 + 实时分页预览。

## 阶段 4：页眉/页脚/页码完善

**目标**：页眉/页脚配置生效。

- [ ] 4.1 页眉/页脚：文本输入框 + "显示页码"勾选（工具栏或属性面板）
- [ ] 4.2 页码格式：`第 {n} 页 / 共 {N} 页`，引擎注入 n/N
- [ ] 4.3 未配置时仍占位（高度=边距）

**产出**：页眉页脚可视化配置 + 页码动态注入。

## 阶段 5：打磨与扩展

- [ ] 5.1 撤销/重做（历史栈）
- [ ] 5.2 schema 序列化/反序列化（保存/加载 JSON）
- [ ] 5.3 组件库扩展：签名、勾选框、日期、分隔线
- [ ] 5.4 测量性能优化（行高缓存、批量测量）

## 优先级与风险

| 阶段 | 优先级 | 风险点 |
|---|---|---|
| 1 | 高 | 引擎抽函数化，注意保留 demo-v2 验证过的测量宽度对齐 |
| 2 | 高 | 低，纯渲染 |
| 3 | 高 | 拖拽排序与分页重算的性能（debounce 策略） |
| 4 | 中 | 页码注入时机（引擎生成 Page[] 时确定） |
| 5 | 低 | — |

## 验证基线

阶段 2 完成后应复刻 demo-v2.html 的全部验证点：

1. JS 分页引擎自动分页
2. 屏幕离散纸张垂直堆叠
3. 表格按行切分 + 表头每页重复
4. grid 容器不跨页（整体推下页留白）
5. 页眉/页脚占位贴纸张顶/底
6. A4/A3 × 横/纵 动态切换 + `@page` 注入
7. 打印复用屏幕 DOM，效果一致
