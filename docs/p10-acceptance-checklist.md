# P10 前五行闭环验收自测清单

> 本清单是 `development-plan.md` §14 的**可执行展开版**，供非实现者独立跑通「前五行闭环」。
> 权威步骤与指标以 `development-plan.md` §14 为准；行级字段/边框以 `docs/acceptance-row-spec.md` 为准。
> **唯一铁律**：验收全程不得修改源码或手写 JSON。任何一步需要改代码/JSON 即判该步未通过。

| 项 | 要求 |

## 1. 验收步骤自测（10 步）

### 步骤 1 — 新建 A4 fixed 模板，基础行高设为 8mm
- **操作**：点击「新建空白」。
- **期望**：画布为 A4、fixed、可用区域无边距漂移；基础行高 = 8mm。
- **依据**：P1.2 A4 fixed 默认配置；P4.2 fixed Page 可用区计算。
- **注意**：默认模板即 A4/fixed/8mm。若需改行高，确认工具栏是否暴露「基础行高」编辑（P5 工具栏项当前未勾，详见 §3 待确认）。

### 步骤 2 — 创建标题（static P）
- **操作**：在外层 Grid 上方插入一个 static P，输入标题文字（如「第二种工作票」）。
- **期望**：标题即时渲染，且为 static 模式（无下划线、无填值框）。
- **依据**：P7.1a 切 static；P7.1b 固定文本编辑（规格表序号 0）。

### 步骤 3 — 创建外层 Grid（all 边框）+ 配置五个内部行的行列数/字段/边框
- **操作**：插入外层 Grid → 选中 Grid 在检查面板设「边框 = all」；按 `acceptance-row-spec.md` 序号 1–5 配置五行：
  - 序号1 单位/编号；序号2 工作负责人_监护人/班组；序号3 工作班成员/人数；序号4 变配电站名称（**整行合并、无内部竖线**）；序号5 工作任务（左格竖排标签 + 右格内嵌两列表格）。
  - 用「列宽 mm/fr/auto」编辑每列宽度；按需插入 P/子 Grid。
- **期望**：外层 Grid 显示四周边框；五行结构与规格表逐行一致；列宽即时反映。
- **依据**：P6.2a 列宽 UI；P6.2e 边框 all/outer/inner/none；P6.3a 按钮插入；P7.2f 表 cell 放 P 或子 Grid（规格表序号 1–5）。

### 步骤 4 — 工作任务行设为 5 倍最小行高
- **操作**：选中工作任务所在 GridRow → 设行高倍数 = 5。
- **期望**：该行高度 = 5 × 8mm = 40mm；其余行 = 1 倍。
- **依据**：P6.1 行高倍数；P4.2 baseRowHeight × height（验收指标「行高稳定」）。

### 步骤 5 — 配置全部 static/field P（字段清单见规格表序号 0–5）
- **操作**：逐格选中 P：
  - 标题/左格「工作任务」标签设为 **static + 竖排（vertical-rl）**；
  - 各输入格设为 **field**，填字段名（与规格表、demoData 键一致）、前/后标签、输入类型（text/number/date/signature）。
- **期望**：竖排标签正确旋转且占位；field P 带下划线/填值框；`data-field` 与 demoData 键一致（填写后能对上数据）。
- **依据**：P7.1a–c static/field + 字段名 + inputType；P7.1d 竖排（规格表序号 5 左格「工作任务」）；P9.1c 输入类型语义。

### 步骤 6 — 工作任务右格创建两列表格（表头 1 / 行高 1 / minRows 4）
- **操作**：在序号5 右格插入 Table → 设列数 2、表头行数 1、行高 1、最小行数 4。
- **期望**：表格渲染 1 表头 + 4 数据行；表头与数据行高度符合；列宽可设。
- **依据**：P7.2c headerHeight/rowHeight/minRows；P7.2b 列宽最小（规格表序号 5 内嵌表）。

### 步骤 7 — 保存并关闭模板
- **操作**：点击「保存」（localStorage 或导出文件）→ 关闭/切换模板。
- **期望**：保存成功提示；无结构 error（保存前校验拦截非法结构，见 P8.4）。
- **依据**：P8.1 序列化；P8.2 持久化通道；P8.4 保存前校验。

### 步骤 8 — 重新加载模板，并修改任意列宽和标签，确认结构与样式保持正确
- **操作**：「重新加载模板」→ 选中某 Grid 改一列宽、改一个标签文字 → 观察渲染。
- **期望**：加载后视觉与编辑状态一致，节点 ID 稳定；改列宽/标签即时反映且不影响其他节点；可继续编辑。
- **依据**：P2.3 ID 稳定；P8.2/P8.3 加载重建 nodeIndex + 可选状态；P8.6 未保存提示。

### 步骤 9 — 填写测试数据
- **操作**：切「预览/填写」态 → 在 field P 与表格 cell 的填值框输入 demoData 对应值 → 改一个值后看右上角 data 是否同步。
- **期望**：预览态显示 data 初始值；手动改值后 `data[field]` 实时回写（关闭重开预览值保留）；复合 P 前后标签不被写回。
- **依据**：P9.1a 从 data 初始化填值；P9.1b 输入事件回写 data（provide/inject）；验收指标「数据回写正确」。

### 步骤 10 — 打印并与参考 HTML/图片比较
- **操作**：浏览器打印预览（Ctrl+P）→ 对照 `demo/云铝-第二种作业票.html` 与基线截图。
- **期望**：A4 纸张、无边距漂移；设计态辅助 UI（面包屑/状态栏/选区高亮）在打印中隐藏，仅业务 DOM；位置/尺寸与参考图一致。
- **依据**：P9.3a A4 @page；P9.3b 隐藏 UI；P9.3c 独立 Preview；P9.3d 不改业务尺寸；P9.3e 溢出提示（验收指标「打印尺寸误差 ≤0.5mm」「主要结构与参考图一致」）。

## 2. 验收指标核对（8 项）

| # | 指标 | 验证方法 | 通过标准 |
|---|---|---|---|
| 1 | 不修改源码或 JSON | 全程仅用 UI 操作 | 10 步无任何一步需改 `.ts`/`.json` |
| 2 | 无结构 error | 保存前校验 + 节点检查面板问题列表 | 无任何 error 级问题，仅允许 warning |
| 3 | 无意外溢出 | P3 溢出警告（P 文本估算 vs 格宽） | 无 PAPER_OVERFLOW / 内容溢出警告 |
| 4 | 行高和边框稳定 | 步骤 4 + 步骤 3 | 工作任务行高 = 40mm；外层 Grid 四边 all 边框清晰、无双边框 |
| 5 | 所有节点可再次选中、移动和配置 | 步骤 8 重加载后逐一点选 Page/Grid/P/Table | 每个节点均可选中并改属性；Row/Cell 仅作布局槽 |
| 6 | 数据回写正确 | 步骤 9 改值后查 data + 关闭重开 | `data[field]` 实时更新、持久；键与 demoData 一致无错位 |
| 7 | 打印尺寸误差不超过 0.5mm | 步骤 10 量测（Chrome/Edge） | A4 量测误差 ≤0.5mm（**需人工真浏览器**） |
| 8 | 主要结构与参考图一致 | 步骤 10 对照基线 | 含左侧「工作任务」竖排、右侧表头 + 4 行输入格，整体一致 |

## 3. 已知待确认 / 待人工项

- ~~**P5 工具栏「纸张/边距/基础行高」未勾**（plan 行 317）~~ **已确认（2026-08-30）**：`DesignerApp.vue` 工具栏已暴露「纸张（A4/A3）」「方向（纵向/横向）」「行高(mm)」三项，步骤 1 可显式设置；**边距（margin）未暴露到工具栏**，但步骤 1 不要求改边距（默认 `10mm` 四周），不记为缺口。
- **P9.3f 打印 0.5mm 门槛**：本环境无浏览器，需验收人在 Chrome/Edge 实机量测（指标 #7）。
- **P9.1c 内部控件（date/signature）**：第一版用 contenteditable 文本兜底；inputType=date/signature 在 schema 已记录但渲染仍为文本输入，验收时按「文本填值」接受即可。
- **内嵌表逐行字段已支持 `{row}`（2026-08-30 已落地，见 plan §11 P7.2e）**：工作任务表 4 行 × 2 列通过行模板占位符 `工作任务_{row}_1` / `工作任务_{row}_2` 各自绑定独立数据键，与 `demoData` 的 8 个键逐字对应。步骤 9 在表格 cell 填值时，第 r 行第 c 列应回写到 `工作任务_r_c`，改一行不影响其他行。设计器中选中表格行模板内的 P，右侧面板会提示 `{row}` 用法。
- **P4.3 边框 all/outer/inner/none 渲染**：Grid 边框已按模式生效（P6.2e 落地）；嵌套 Grid 双边框、Table/GridCell 边界重复、colspan 后格线属 P4.3 未勾项，前五行结构（外层 all + 内嵌表无嵌套 Grid）不触发，验收可忽略。
