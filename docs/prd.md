### 表单打印纸张尺寸说明文档
需求和使用场景：
以电子表单的形式，在浏览器里模拟表单打印在纸张上的效果，在打印时则移除虚拟纸张，打印表单内容。
无论A3还是A4，纸张需要打印的内容包含 标题 和 子表单，区别是A3打印时，子表单分水平两列，间隔12mm。标题任何时候都是在纸张顶部独一行居中（固定位置）。

基础纸张物理规格
纸张类型
A3:420mm × 297mm
A4:210mm × 297mm
打印页边距统一：@page margin:12mm
A3 可打印区域高度：297‑12‑12 = 273mm
Chrome 打印引擎特性：内容高度等于可用打印高度时，会判定内容溢出，触发强制分页，需要预留安全余量。
一、Screen 屏幕虚拟 A4 纸张（浏览器预览，开发调试）
DOM 结构：.wrapper > .paper，每张.paper代表一张虚拟 A4 纸张
由外至内层级：红色示意边框 → 纸张内边距 → 标题 → 子表单（蓝色示意边框）→ 业务内容区
1. 虚拟纸张外壳 .paper
- 纸张外壳总尺寸：210mm × 297mm
- 调试示意边框：1mm solid red（仅屏幕显示，打印不输出）
- 纸张内边距 padding：12mm（上下左右）
2. 标题 .paper__header
- 高度：14mm
3. 子表单 .subform（border‑box 盒模型）
- 子表单元素外部尺寸：184mm × 257mm
- 调试示意边框：1mm solid blue
- 业务内容可用区（扣除蓝边框）：182mm × 255mm
业务内所有position:absolute定位坐标以该内容区左上角为原点。
4. 屏幕布局行为
- 多个.paper垂直堆叠，每一张.paper独立一张虚拟 A4；
- 每张纸内部：标题 + 单个子表单；
- 红框、蓝框均可见，用于开发校验尺寸。
二、Print A3 横向打印纸张（A3‑landscape，开发阶段保留蓝色调试边框）
DOM：复用同一套.wrapper + 多组.paper，利用display:contents穿透 paper 外壳做 flex 两栏重排，DOM 结构不复制、不新增视图容器。
打印阶段：红色纸张示意边框完全清除，不占用空间；仅保留子表单蓝色调试边框。
1. @page 配置
@page {
  size: A3 landscape;
  margin:12mm;
}
- A3 可打印高度：273mm
- 可打印宽度：420‑12‑12 = 396mm
2. 全局打印标题
- 仅渲染第一个.paper内的标题，其余 paper 内部标题隐藏；
- 标题高度：14mm；
- 标题底部安全间隙：1mm，规避临界高度分页。
3. 子表单布局规则
- flex 两栏并排，栏之间隔 gap：12mm；
- 子表单元素外部尺寸：192mm × 257mm（修改降低高度预留安全余量）
- 调试示意边框：1mm solid blue（开发开启，上线置为 none）
- 业务内容可用区（扣除蓝边框）：190mm × 257mm
业务 absolute 定位坐标不变，只压缩子表单外层盒子高度，内部业务内容区域尺寸不受改动。
4. 总占用高度校验（预留安全余量，避免换页）
$$\text{标题高度} + \text{标题底部间隙} + \text{子表单元素高度}=14\mathrm{mm}+1\mathrm{mm}+257\mathrm{mm}=272\mathrm{mm}$$
272mm ＜ A3 可用打印高度 273mm，留出 1mm 安全余量，消除 Chrome 打印临界分页 bug。
三、尺寸公式溯源
屏幕虚拟 A4 子表单业务内容区
- 宽度：210mm - 24mm(padding) - 2*1mm(红边框) - 2*1mm(蓝边框) = 182mm
- 高度：297mm - 24mm(padding) -14mm(标题) -2*1mm(红边框) -2*1mm(蓝边框) = 255mm
A3 打印单个子表单业务内容区
- 单个子表单宽度：(420mm‑24mm(打印边距)‑12mm(两栏gap)‑4*1mm(两个子表单蓝边框总宽度)) / 2 =190mm
- 子表单业务高度：297mm‑24mm(打印边距)‑14mm(标题)‑2*1mm(蓝边框)=257mm
四、行为对比总览
项目
Screen 屏幕预览
Print A3 横向打印
DOM 容器
单一.wrapper，多个.paper，无重复 DOM
复用同一套 DOM，CSS 重排，不复制节点
纸张外壳
每一个.paper是独立 A4 红框虚拟纸张
.paper使用display:contents穿透，外壳盒子消失，红框移除
标题表现
每张 paper 都渲染一份标题
仅第一个 paper 标题作为全局标题，其余全部隐藏
子表单排布
垂直排列，一张纸放 1 个子表单
flex 两栏并排，gap=12mm
调试边框
红框 + 蓝框全部可见
仅保留蓝色子表单边框，红框不输出
总内容高度
每张 A4 占 297mm
合计 272mm，小于 A3 打印可用高度 273mm，防止异常换页
五、上线发布修改项
打印模式中，将子表单蓝色调试边框关闭：
.subform{
  border: none !important;
}
六、关键注意事项
1. 业务内部所有position:absolute坐标均以子表单业务内容区左上角作为原点，不要参考蓝色边框外侧；
2. 修复分页问题只修改子表单外层元素高度，严禁修改业务内容可用区尺寸；
3. 使用display:contents实现 DOM 不复制重排，兼容 Chrome、Edge 现代浏览器。
