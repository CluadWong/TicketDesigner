- 关键接线（避免后人在拆分中踩坑）：
  - `useSchemaDocument(initialSchema?, { onReset })`：`onReset` 只在「读取本地 / 导入文件」成功替换文档后触发，宿主在此清选中；`resetHistory` 本身不触发（调用方 loadSample/resetBlank/import 已自行清）。
  - 声明顺序坑：`onReset` 需要 `clearSelection`，而 `clearSelection` 来自 selection（selection 又依赖 document 的 schema）→ 用 `let onDocumentReset: () => void = () => {}` 占位、装配后赋值，避免 TDZ。
  - undo/redo 在**壳层**包装（`schemaDoc.undo(); clearSelection();`），composable 保持纯粹。
  - `useSchemaEdits({ document, selection, editable, clearSelection })`：editable 传 getter（不在创建时求值），一切结构编辑经单一闸门。
  - `useFillData({ canvasEl, isPreview, enterPreview })`：导入/读取本地后经 `enterPreview(data)` 进入预览态（避免宿主用 seed 覆盖刚导入的数据）。
- 新增测试 `composables/__tests__/useSchemaDocument.test.ts`(7) + `useSchemaEdits.test.ts`(4)：首次让 commit/undo/redo/tag 合并窗口/持久化/编辑闸门脱离 DOM 单测。

## 弹性布局 Flex（三十五续，按用户澄清改为 cell 级）
- 用户需求：弹性格子 Flex，功能定位与 Grid 类似，默认水平方向、可换行、水平左对齐、垂直居中、间隔 0；并授权「若 cell 能实现 flex 布局，直接复用 Grid + 加配置」。
- **反转（用户反馈）**：用户明确「flex 应直接在 cell 上加配置，不要额外加 flex 组件」——grid 级 `display` 方案被推翻。已回退：`GridNodeV2` 不引入 `display` 字段、`createFlexGridNodeV2` 工厂删除、`NodeKind` 不含 `flex`、`addFlexGrid`/`updateGridDisplay` 移除、调色板无 Flex 按钮、`GridInspector` 无「布局」切换（行数始终渲染）。
- **最终落地（cell 级）**：flex 是 `GridCellV2.flex?: boolean` 单元格属性（默认 false，存量/新建零影响）。渲染内核 `GridSchemaNode.vue` 在普通 cell 上按 `cell.flex` 分支：`cellStyle` 给 flex cell 补 `flex-wrap:wrap; justify-content:flex-start; align-items:center`；CSS 新增 `.layout-grid__cell--flex`（wrap/左/垂直居中）+ 子节点覆盖 `.layout-grid__cell--flex > .layout-p, > .layout-text { flex:0 1 auto; width:auto }`（关键：`.layout-p`/`.layout-text` 原 `width:100%` 会强制每个子节点独占一行、破坏水平流，必须覆盖）；cell 仍承载 children 递归渲染。
- `useSchemaEdits.ts` 新增 `updateSelectedCellFlex()`（勾选写 `flex:true`、取消写 `undefined`），`clearCellOverride` 一并清 `flex`；`CellInspector.vue` 顶部加「弹性布局」勾选（`data-flex`）。序列化 `normalizeNode` 透传未知字段、校验仅查 rows≥1，管线零改。
- 测试：`schema-v2-operations.test.ts` 删除工厂测试；`GridSchemaNode.flex.test.ts` 改写为 cell 级（3 例：flex 单元内联样式+子节点递归、非 flex cell 无 `--flex` 类、序列化往返保留 `cell.flex`）。
- 验证：vue-tsc 干净；全量 vitest **260/260（33 文件）** 零回归。
- 精修（同轮）：flex cell 对齐改为完全复用 cell 的 `align`/`verticalAlign` 配置——`cellStyle` 两分支合并，flex 仅多 `flex-wrap:wrap`；CSS `.layout-grid__cell--flex` 去掉硬编码 `justify-content`/`align-items`（基础 cell 已是 `display:flex` row，故只需 wrap）。默认由「左+中」变为「中+中」（继承 cell 默认），需左对齐在该 cell Inspector 设「水平对齐=左」。`GridSchemaNode.flex.test.ts` 增「`align:'left'→flex-start`」例（3→4）。验证 vue-tsc 干净、vitest **261/261（33 文件）**。
- UI 清理：移除 `CellInspector` 的「清除覆盖（恢复 Grid 默认）」按钮；`clearCellOverride` 仅被该按钮使用，顺带删除孤儿函数（useSchemaEdits 函数体 + return + DesignerApp 解构，共 3 处）。`vue-tsc` 干净、vitest **261/261（33 文件）**。
