## 批次 1 已落地（用户选定，三十二续）

- `DesignerApp.vue` 2813 → 1760 行（script 1329 → 279），只剩「装配四个 composable + 视图模式/分页/快捷键/校验派生 + 895 行模板 + 585 行 CSS」。模板与所有 `data-*` 选择器零改动 → 三个 DesignerApp 测试零改动全绿。
- 关键接线（避免后人在拆分中踩坑）：
  - `useSchemaDocument(initialSchema?, { onReset })`：`onReset` 只在「读取本地 / 导入文件」成功替换文档后触发，宿主在此清选中；`resetHistory` 本身不触发（调用方 loadSample/resetBlank/import 已自行清）。
  - 声明顺序坑：`onReset` 需要 `clearSelection`，而 `clearSelection` 来自 selection（selection 又依赖 document 的 schema）→ 用 `let onDocumentReset: () => void = () => {}` 占位、装配后赋值，避免 TDZ。
  - undo/redo 在**壳层**包装（`schemaDoc.undo(); clearSelection();`），composable 保持纯粹。
  - `useSchemaEdits({ document, selection, editable, clearSelection })`：editable 传 getter（不在创建时求值），一切结构编辑经单一闸门。
  - `useFillData({ canvasEl, isPreview, enterPreview })`：导入/读取本地后经 `enterPreview(data)` 进入预览态（避免宿主用 seed 覆盖刚导入的数据）。
- 新增测试 `composables/__tests__/useSchemaDocument.test.ts`(7) + `useSchemaEdits.test.ts`(4)：首次让 commit/undo/redo/tag 合并窗口/持久化/编辑闸门脱离 DOM 单测。
