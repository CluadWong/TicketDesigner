- 问题：填写态字段为 `contenteditable`，被 `PaperViewport` 打 `panzoom-exclude`，导致拖拽表单只能在空白处平移，字段上无效。

- 仅作用于「字段」(`input/textarea/select/[contenteditable]`)，**不误伤设计态 `[draggable]` 节点拖拽**——`tagExclusions` 仍用全量 `EXCLUDE_SELECTOR` 打标，`setExclusions`/`onPointerDownCapture` 只用 `FIELD_EXCLUDE_SELECTOR`。
- 平移态跳过 MutationObserver 重打排除标记；视口加 `--pan`/`--grabbing` 光标（覆盖字段 `!important`）；缩放条加「空格 / 中键拖拽平移」提示。

## 修复：design→preview 切换后「拖拽非输入组件允许平移」失效（Request 5）
- 现象：设计态、独立 /preview 页平移符合预期；但在设计器内由设计态切到预览态后，拖拽纸张上的非字段位置（文本/图片/Grid 等非输入组件）无法平移。
- 根因：`PaperViewport.tagExclusions` 只 `classList.add("panzoom-exclude")`、**从不移除**。设计态 `CanvasSurface.applyNodeDraggable` 给所有节点设 `draggable="true"`（命中 EXCLUDE_SELECTOR）→ 打标；切预览态移除 `draggable` 后，过期 `panzoom-exclude` 永留 → 非输入组件仍被排除、无法平移。独立 /preview 节点从未 draggable，故无此残留、正常。
- 修复：`tagExclusions` 改为「先清后打」reconcile——先 `querySelectorAll(".panzoom-exclude")` 全部移除，再按当前 EXCLUDE_SELECTOR 重新打标。MutationObserver（attributeFilter 已含 `draggable`）在 `draggable` 移除时触发 reconcile，节点即时恢复可平移；字段（contenteditable）始终命中、持续排除（输入优先）。design 态 /preview 行为均不变。
- 测试：PaperViewport.test.ts 新增 2 例（draggable 移除后 panzoom-exclude 被清除可平移；contenteditable 字段移除 draggable 后仍排除）。vue-tsc 干净；vitest 237/237（29 文件）全绿。

## 调研：Grid 内嵌套多层并列 Grid（Task B）
- 结论：**数据模型/渲染/拖拽/按钮入口早已支持嵌套 Grid**，本次结构树可见性是最后一块拼图（已补）。
  - 数据：`GridCellV2.children: FormNodeV2[]`，`FormNodeV2` 含 `GridNodeV2` → cell 内可放 grid。
  - 渲染：`GridSchemaNode` 递归展开 grid→rows→cells→children，嵌套 grid 自动渲染。
  - 按钮：`addGrid()` 在已选 cell（`insertionSlot`）时走 `addNodeToSelectedCell("grid")` → 在 cell 内建 grid；否则加页面。
  - 拖拽：`onDropPalette`（拖「格子 Grid」到任意 cell，含嵌套 cell）、`onDropNode`（移动已有 grid 入嵌套 cell）均支持；`legalDropCellIds` 递归收集嵌套 grid 的 cell 为合法落点。
- 并列（side-by-side）grid：父 grid 多列、各列 cell 内放子 grid 即得；同 cell 多子节点按 flex 排列。
- 待观察（未改）：① 分页引擎对嵌套 grid 的切分边界（外层按行切、内层随 cell 保留）；② 深嵌套下结构树节点数膨胀（可折叠，已接受）。后续若要正式立项再做针对性验证。
